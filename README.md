# Price Monitor на Node-RED

Бот моніторингу цін на Node-RED: щодня перевіряє ціни товарів, пише в Telegram, коли ціна впала, і приймає команди прямо в чаті (`/add`, `/list`, `/remove`, `/check`).

Побудований як візуальний флоу Node-RED з діалоговим інтерфейсом у Telegram.

## Можливості

- **Щоденна перевірка** о 09:00 (за локальним часом комп'ютера) і кнопка «Перевірити зараз».
- **Сповіщення про падіння ціни** з градацією: 🔻 будь-яке зменшення, 📉 10%+, 📉 15%+, 🔥 20%+, 🔥 більше 25%.
- **Діалог у Telegram:** додавати, переглядати й видаляти товари без редагування файлів.
- **Магазини:** `comfy.ua` та будь-який сайт з мета-тегом `product:price:amount` / schema.org / JSON-LD; `auto.ria.com` (мінімальна ціна пошукової видачі або ціна конкретного оголошення).
- **Історія цін** (останні 180 записів на товар) і список товарів зберігаються на диску й переживають перезапуск.
- Лише **стандартні ноди** Node-RED, жодних сторонніх пакетів.

## Вимоги

- Node.js 18+ і Node-RED .
- Telegram-бот від **@BotFather** (токен) і chat_id`.

## Встановлення

### 1. Увімкнути файлове сховище контексту

Відкрити `settings.js` Node-RED (зазвичай `~/.node-red/settings.js`), знайти блок `contextStorage` (він закоментований) і зробити так:

```js
contextStorage: {
    default: { module: "memory" },
    file:    { module: "localfilesystem", config: { flushInterval: 5 } }
},
```

Без цього список товарів і історія цін губитимуться при перезапуску. Назва сховища має бути саме `file`.

### 2. Задати змінні середовища

| Змінна | Значення |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен  |
| `TELEGRAM_CHAT_ID` |  chat_id (див. нижче) |

Linux / macOS:
```bash
export TELEGRAM_BOT_TOKEN="123456:ABC..."
export TELEGRAM_CHAT_ID="123456789"
node-red
```

Windows PowerShell:
```powershell
$env:TELEGRAM_BOT_TOKEN="123456:ABC..."
$env:TELEGRAM_CHAT_ID="123456789"
node-red
```


### 3. Імпорт флоу

1. Відкрити редактор: <http://localhost:1880>.
2. Меню (☰) → **Import** → **select a file to import** →  `flow.json`.
3. Натиснути **Deploy**.

Через ~3 секунди бот почне опитувати Telegram. Напиши йому `/help`.

## Команди бота

| Команда | Що робить |
|---|---|
| `/add <посилання> [назва]` | додає товар; тип сайту визначається автоматично |
| `/list` | показує відстежувані товари з останніми цінами |
| `/remove <номер або id>` | видаляє товар зі списку |
| `/check` | перевіряє всі ціни зараз і звітує по кожному |
| `/help` | підказка |

Команди приймаються лише з чату, заданого в `TELEGRAM_CHAT_ID`. З чужих чатів вони ігноруються.

Приклад:
```
/add https://comfy.ua/ua/smartfon-samsung-galaxy-a17-8-256gb-gray-sm-a175fzaeeuc.html
/add https://auto.ria.com/uk/search/?query=chevrolet+bolt+ev Bolt EV пошук
/check
```

Перша перевірка нового товару лише запам'ятовує базову ціну. Сповіщення про падіння приходять, починаючи з наступної перевірки.

## Як це працює

Флоу складається з трьох ланцюжків на одній вкладці:

1. **Перевірка цін:** `inject` (cron 09:00 або кнопка) → `function` (список товарів) → `delay` (1 запит / 2 с) → `http request` → `function` (парсинг ціни, порівняння, історія) → Telegram.
2. **Команди:** `inject` (кожні 5 с) → `function` (getUpdates) → `http request` → `function` (обробка команд) → відповідь у Telegram або запуск ручної перевірки.
3. **Ініціалізація:** при запуску записує стартовий список (Comfy + AUTO.RIA), якщо він ще не створений.

Рішення, які варто знати:

- **Черга відправки** (`delay`, 1 повідомлення / с): без неї запити до Telegram летять паралельно і відповіді приходять у довільному порядку. Це знайшов наскрізний тест. Черга також вкладається в ліміт Telegram.
- **Захист від накладання опитувань** (`pollLock`): якщо попередній `getUpdates` ще не завершився, новий не запускається. Це запобігає подвійній обробці команд.
- **Offset зберігається на диску:** після перезапуску бот не відповідає на старі команди повторно.
- **Помилки мережі** (`catch`-нода): збій одного магазину не зупиняє перевірку інших. Про `403` у плановому режимі сповіщення не надсилається, у ручному (`/check`) надсилається. Про «ціну не знайдено» бот попереджає один раз, а не щодня.
- **Опитування, а не webhook:** `getUpdates` працює без публічної адреси, тож підходить для запуску на домашньому комп'ютері.

## Тестування

Юніт-тести логіки всіх функцій (парсинг, пороги, команди), 16 тестів:

```bash
node test_functions.js
```

Окрім цього, флоу було запущено в справжньому Node-RED 5.0.9 проти локальних імітацій Telegram API та магазину. Перевірено: старт без помилок; `/start`, `/list`, `/add`, `/remove`, `/check`; ігнорування чужого чату; збереження базової ціни; сповіщення при падінні 15% і 29%; запуск «щоденної» перевірки; порядок повідомлень; запис стану на диск.

## Автозапуск

Щоб бот працював після перезавантаження комп'ютера, запускати Node-RED як службу:
- Linux: `systemd` (змінні задай у `Environment=` юніта) або `pm2`.
- Windows: `pm2` / NSSM, змінні задай у системних змінних середовища.
- Raspberry Pi: офіційний скрипт встановлення Node-RED додає `systemd`-службу.
